# 🛍️ Customer Segmentation using K-Means Clustering

This project performs customer segmentation using the **K-Means Clustering algorithm**. The goal is to identify distinct customer groups based on their purchasing behavior, demographics, and interactions with marketing campaigns.


---

## 📊 Dataset Overview

This dataset contains information about customers, their demographics, and product consumption patterns.

| Column         | Description |
|----------------|-------------|
| `ID`           | Customer ID |
| `Year_Birth`   | Birth year |
| `Education`    | Education level |
| `Marital_Status` | Marital status |
| `Income`       | Yearly income |
| `Kidhome` / `Teenhome` | Number of kids/teenagers at home |
| `Recency`      | Days since last purchase |
| `MntWines`, `MntFruits`, ... | Money spent on product categories |
| `NumWeb`, `NumCatalog`, `NumStore` | Channel interactions |
| `AcceptedCmp1-5`, `Response` | Campaign responses |
| `Complain`, `Z_CostContact`, `Z_Revenue` | Other metadata |
